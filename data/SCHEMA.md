# Data schema (scraper output contract)

All files are YAML, UTF-8, generated by scripts in `scripts/`. Course identity is the
catalog code with a single space: `PHYS 231N`, `MATH 211`, `ENGL 110C`.

Every generated file starts with a provenance block:

```yaml
meta:
  source: https://catalog.odu.edu/...
  scraped_at: "2026-08-09"
  catalog_year: "2026-2027"
```

## `courses.yaml`

```yaml
meta: {...}
courses:
  - code: PHYS 231N
    subject: PHYS
    number: "231N"
    title: University Physics I
    credits: {min: 4, max: 4}      # ranges exist: PHYS 297 is 1-3
    description: "A general introduction to physics..."
    prereq: <EXPR|null>            # see Expressions below
    coreq: <EXPR|null>             # strict corequisite ("Corequisite:")
    precoreq: <EXPR|null>          # "Pre- or corequisite:" — satisfied by earlier OR same term
    terms: [fall, spring, summer]  # parsed from "(offered fall, spring)" in description;
                                   # null when the catalog does not say
    attributes: [W]                # W = writing intensive, from the code suffix / text
    crosslist: [PHYS 425, PHYS 525]  # when the header is "PHYS 425/525"
    raw_prereq_text: "MATH 211 with a grade of C or better"
    raw_precoreq_text: "MATH 212"
```

### Expressions

Prerequisites are a recursive boolean tree. Keep it small and total:

```yaml
# leaf — a course, optionally with a minimum grade
{course: "MATH 211", min_grade: C}

# leaf — something we could not resolve to courses; planner treats as a soft note
{note: "Permission of the instructor"}

# leaf — a test score / placement
{placement: "Math placement level 4"}

# branches
{all_of: [<EXPR>, ...]}
{one_of: [<EXPR>, ...]}
{n_of: {n: 2, options: [<EXPR>, ...]}}
```

Parser rules: `and`/`;` → `all_of`, `or` → `one_of`. When precedence is ambiguous
in the source English, prefer the reading the catalog links imply and record the
original in `raw_prereq_text` so a human can audit it. Never silently drop a clause —
emit `{note: "..."}` for anything unparsed.

## `gened.yaml`

```yaml
meta: {...}
categories:
  - id: nature            # matches the catalog anchor (#nature)
    name: The Nature of Science
    credits: 8
    notes: "Must include two courses with labs from different disciplines"
    # Courses that satisfy it. `any_approved` means the list is the approved list.
    approved: [BIOL 108N, CHEM 121N, PHYS 231N, ...]
  - id: language
    name: Language and Culture
    credits: 6
    waivable: true
    notes: "May be satisfied by high school coursework; see catalog"
    approved: [...]
```

Note: `language` is modeled as an ordinary category. Waiver is expressed per-student
as a satisfied requirement in the student file, not as a flag here.

## `programs/<slug>.yaml`

One file per degree program.

```yaml
meta: {...}
program:
  id: physics-astrophysics-bs
  name: Physics with a Major in Astrophysics (BS)
  degree: BS
  department: Physics
  total_credits: 120
  # Requirement groups, in catalog order.
  requirements:
    - id: major-core
      name: Physics Core
      # exactly these courses
      all_of: [PHYS 261N, PHYS 262N, PHYS 303, ...]
    - id: astro-electives
      name: Astrophysics Electives
      credits: 6                  # need N credits from the pool
      one_of: [ASTR 450, ASTR 460, ...]
    - id: upper-div-elective
      name: Upper-Division Elective
      credits: 3
      filter: {level_min: 300, subject: [PHYS, ASTR]}   # when the catalog describes a rule, not a list
      notes: "Any 300+ PHYS or ASTR course not used elsewhere"
  # Courses in this program that also satisfy a gen-ed category (double-count rules).
  # Derived from the catalog's own annotations; when unstated, leave it out.
  double_counts:
    - course: MATH 211
      satisfies: math
    - course: PHYS 231N
      satisfies: nature
  # The catalog's own recommended sequence, verbatim.
  plan_of_study:
    - year: Freshman
      term: Fall
      credits: 14
      items:
        - {course: PHYS 231N}
        - {one_of: [CHEM 121N, CHEM 122N], credits: 4}   # "CHEM 121N and CHEM 122N" cells
        - {placeholder: "Elective or Language & Culture I", credits: 3, category: language}
```

`placeholder` items are cells the catalog leaves to the advisor. When the text maps
onto a gen-ed category, set `category:` to that category id so the planner can fill it.

## Fidelity rules

- Never invent a course, credit count, or prerequisite. If the catalog is silent, omit the
  key rather than guessing.
- Preserve the catalog's own wording in `notes` / `raw_*` fields.
- Where a parse is uncertain, add `needs_review: true` to that record. The app surfaces
  these so an advisor can audit them.
